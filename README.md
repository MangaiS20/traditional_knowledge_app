# Traditional Knowledge Database with OCR Annotation

## Overview
This project is a Flask-based web application developed to preserve and retrieve traditional knowledge manuscripts. It supports multilingual text management, OCR-based manuscript annotation, and role-based access.

## Features
- User and Admin Login
- Add Traditional Texts
- Search Records
- View Records
- Update/Delete Records (Admin)
- Approve User Submissions
- OCR Annotation using Tesseract
- MongoDB for OCR Storage
- MySQL for Traditional Knowledge Database

## Technologies
- Python
- Flask
- MySQL
- MongoDB
- HTML
- CSS
- Bootstrap
- Tesseract OCR

## OCR Languages
- English
- Tamil
- Sanskrit
